# televideo
## carmine-alberto.github.io/televideo


### Compatibility
-  LG TVs using Magic Remote
-  Touchscreen devices
-  PCs


### Controls
- NumPad (default mode: 3 columns; cog toggle: 2 columns with reduced size)
- Arrows (both on PC keyboard and remote): Up-Down to change page, Left-Right to change subpage (if available on the current page)
